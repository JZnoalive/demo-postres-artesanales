# Demo Repostería y Postres — Pedido Directo & Carrito por WhatsApp

Plantilla web comercial para emprendimientos de repostería, tortas y cafés que muestra vitrina visual, calcula totales con domicilio y envía pedidos armados a WhatsApp.

## Stack y herramientas
- **Framework y lenguaje:** Next.js 15 (App Router) + TypeScript estricto.
- **Estilos y animaciones:** Tailwind CSS v4, Framer Motion y Lucide React.
- **Calidad y QA:** Pruebas unitarias en `tests/qa.test.ts` bajo el patrón AAA (Arrange - Act - Assert).
- **Flujo asistido y automatización con IA:** Construida mediante Skills de optimización de tokens, coordinación multi-IA y datos centralizados en `src/data/postres.ts` para replicar catálogos rápidamente.

## Comandos principales
- `npm install` — Instalar dependencias.
- `npm test` — Ejecutar suite de pruebas QA.
- `npm run build` — Compilar para producción (Vercel).
- `npm run dev` — Iniciar servidor local.
